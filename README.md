A tiny stack virtual machine in one TypeScript file (Node 22, no dependencies), with the ISA's exact semantics: wrapping 32-bit arithmetic, a 256-value stack, a 64-deep call stack, 256 memory words, and all ten traps. Pure computation, so every run reproduces byte for byte. For each instance it runs `program.bin` on `input.bin` and writes `stdout.bin` and `exit.txt`.

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
